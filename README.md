# أشرف الخلق

تطبيق ويب عربي متجاوب (PWA) كبداية مستقلة لمشروع صدقة جارية.

## المزايا الموجودة في هذه النسخة
- واجهة عربية RTL متجاوبة مع الهواتف.
- سبحة إلكترونية: عداد، أذكار جاهزة وذكر مخصص، هدف يومي، اهتزاز اختياري، وحفظ محلي للعداد والسجل.
- عرض سور القرآن وآياتها من واجهة AlQuran Cloud، مع اختيار قارئ وبدء تلاوة صوتية للسورة (يعتمد على توفر خدمة الصوت والإنترنت).
- جلب مواقيت الصلاة بعد موافقة المستخدم على مشاركة موقعه عبر AlAdhan، مع إعدادات طريقة الحساب وإدخال الإحداثيات يدويًا.
- أيقونة للتطبيق وملف Manifest ودعم التثبيت كتطبيق ويب (PWA).\n- شاشة إعدادات محلية للغة/اتجاه العرض، وخلفية واجهة الأذان، واختيار صوت التنبيه، وطريقة حساب المواقيت، وإعداد تذكير الصلاة على النبي (واجهة الإعداد موجودة؛ الجدولة الصوتية الأصلية لم تكتمل بعد).\n- واجهة أولية لوقت الصلاة وأزرار طلب أذونات الإشعارات والظهور فوق التطبيقات في نسخة Android.
- تخزين الملفات الأساسية مؤقتًا للعمل دون اتصال بعد أول تحميل ناجح.

## التشغيل محليًا
يفضل تشغيله عبر خادم محلي أو استضافة HTTPS؛ تحديد الموقع وService Worker والتثبيت لا تعمل بصورة موثوقة عند فتح الملف مباشرةً من مدير الملفات.

## النشر
يمكن نشر الملفات الثابتة كما هي على GitHub Pages أو Cloudflare Pages أو أي استضافة Static تدعم HTTPS. اجعل مجلد المشروع هو مجلد النشر، وملف `index.html` هو نقطة الدخول.

## حدود النسخة الحالية — مهم
- هذه نسخة أولية قابلة للتجربة وليست إصدارًا نهائيًا أو APK أصليًا.
- القرآن والمواقيت يعتمدان على خدمات خارجية والإنترنت؛ يجب مراجعة النص القرآني وطريقة حساب المواقيت مع مصادر موثوقة قبل الإطلاق.
- السجل والعداد محفوظان على الجهاز نفسه فقط، ولا توجد مزامنة سحابية.
- لم تُنفّذ حسابات المستخدمين أو لوحة الإدارة أو إشعارات التسجيل؛ هذه تحتاج Backend آمنًا وقواعد خصوصية وتقليل البيانات المجمعة.\n- إعداد تذكير الصلاة على النبي موجود كواجهة تفضيلات فقط، ولا يرسل تذكيرات دورية حتى الآن.\n- لا تُفتح واجهة التطبيق تلقائيًا فوق تطبيق آخر عند الأذان؛ النظام يعرض إشعارًا، وفتح الواجهة يكون بضغط المستخدم عليه.\n- صورة أشرف المرسلة لم تُدمج بعد كملف داخل حزمة التطبيق، كما أن تصميم الشاشة التذكارية النهائي يحتاج إدراج الصورة الأصلية بعد تجهيزها.
- لا يوجد أذان تلقائي مضمون في الخلفية أو ظهور فوق التطبيقات في هذه النسخة؛ ذلك يتطلب تطبيق Android أصليًا واختبارات على الأجهزة وإدارة أذونات النظام والبطارية.
- لم تُضف صورة أشرف؛ يلزم أن يرسلها صاحب المشروع وأن تكون لديه موافقة مناسبة على استخدامها.

## تجهيز نسخة Android — قيد البناء والاختبار
- أُضيف إعداد Capacitor ومهمة GitHub Actions لبناء APK تجريبي عند تحديث ملفات التطبيق.
- تتضمن نسخة Android المولّدة طلب إذن الإشعارات، وطلب إذن الظهور فوق التطبيقات عبر إعدادات النظام، وخدمة أمامية بإشعار مستمر عند تشغيلها يدويًا.
- **تنبيه:** خدمة الخلفية الحالية لا تجدول مواقيت الصلاة ولا تشغّل ملف الأذان تلقائيًا. يلزم تنفيذ واختبار جدولة أصلية وصوت الأذان قبل اعتبار هذه الميزة مكتملة.
- ملف APK لا يُعد جاهزًا إلا بعد نجاح مهمة البناء وتنزيل الـ artifact واختباره على جهاز Android فعلي.
- مساحة صورة أشرف موجودة كعنصر مؤقت؛ تُستبدل بالصورة الأصلية التي يرسلها صاحب المشروع.
