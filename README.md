# أشرف الخلق

تطبيق إسلامي قيد الاختبار، بواجهة ويب قابلة للتثبيت (PWA) وبناء Android عبر Capacitor.

## الوظائف الموجودة في الواجهة
- واجهة عربية متجاوبة، أقسام القرآن والسبحة والأذكار والخلفيات والإعدادات.
- سبحة إلكترونية مع ذكر مخصص وهدف واهتزاز وحفظ محلي للعداد وسجل الجلسات.
- عرض سور القرآن وآياتها وتشغيل تلاوة السورة باختيار القارئ عبر AlQuran Cloud/CDN، مع زر لتنزيل ملف السورة كاملًا وحفظه محليًا عبر IndexedDB للاستماع دون إنترنت على نفس الجهاز.
- مواقيت الصلاة عبر AlAdhan، مع تحديد الموقع أو إدخال الإحداثيات واختيار طريقة الحساب.
- إعدادات محلية للغة/اتجاه الواجهة (العربية فعليًا حاليًا)، ألوان واجهة الأذان، نغمة إشعار النظام/الصامت، والاهتزاز.
- اختيار أحد ثلاثة ألوان لخلفية واجهة الأذان من صفحة الخلفيات، مع حفظ الاختيار.
- تذكير بالصلاة على النبي كل 30 دقيقة في نسخة Android: إشعار ومحاولة نطق العبارة بواسطة محرك تحويل النص إلى كلام العربي في الهاتف.
- صورة أشرف التذكارية مضافة إلى `assets/memorial.webp` وتظهر في الشاشة الرئيسية.

## تشغيل الويب
انشر محتويات المستودع على استضافة HTTPS مثل GitHub Pages. القرآن والمواقيت يحتاجان اتصالًا بالإنترنت. بيانات السبحة والإعدادات محفوظة محليًا على الجهاز ولا تتم مزامنتها بين الأجهزة.

## بناء Android
ملفات Capacitor وسكريبت إعداد Android وGitHub Actions موجودة. سير العمل يبني APK تجريبيًا عند تغييرات الملفات المحددة، ثم يرفع artifact باسم `ashraf-al-khalq-debug-apk`.

## قيود مهمة قبل النشر العام
- **نجاح GitHub Actions يثبت بناء APK تجريبي فقط. لا يوجد حتى الآن إصدار Release موقّع بمفتاح نشر خاص، ولم يتم اختبار التطبيق على هاتف فعلي.**
- تنبيه الصلاة الحالي إشعار Android بصوت النظام أو صامت حسب الاختيار؛ **ليس ملف أذان بصوت مؤذن**. إضافة تسجيل أذان مرخّص ومختبر ما زالت مطلوبة.
- توقيت التنبيهات يستخدم Android `setAndAllowWhileIdle` غير الدقيق؛ قد يتأخر بسبب وضع توفير البطارية أو قيود الشركة المصنّعة. لا يوجد ضمان لفتح التطبيق تلقائيًا فوق YouTube أو أي تطبيق آخر؛ الضغط على الإشعار يفتح واجهة الصلاة.
- تذكير الصلاة على النبي يستخدم TTS الموجود على الهاتف؛ جودة الصوت وتوفر اللغة العربية يعتمدان على محرك الهاتف، وقد يتأخر المنبه بسبب قيود النظام.
- إذن الظهور فوق التطبيقات لا ينشئ وحده نافذة عائمة؛ لا توجد حاليًا نافذة Overlay منفذة، ولا ينبغي منح الإذن لهذا الغرض في هذه النسخة.
- اللغة الإنجليزية معروضة كخيار معطّل وليست ترجمة مكتملة.

- لا يوجد تسجيل حسابات أو لوحة إدارة أو إشعارات تسجيل مستخدمين؛ هذه تحتاج Backend آمنًا وسياسة خصوصية.
- الإشعارات قد تتطلب منح إذن Android 13+ يدويًا. يجب مراجعة أذونات الموقع والإشعارات والبطارية على أجهزة متعددة.
- تنزيل الصوت يتم بطلب المستخدم وعلى جهازه فقط؛ يجب إظهار اسم القارئ ومصدر الصوت واحترام شروط مزود التلاوة. لا تزال قائمة القراء محدودة بالمعرفات المضافة في الواجهة، وليست كل القراء المتاحين عالميًا.
- لا يوجد حتى الآن ملف أذان مدمج أو تشغيل أذان حقيقي عند دخول الوقت. صفحة AlAdhan توفر تسجيلات للتنزيل، لكن حقوق التسجيلات تختلف ولا توجد رخصة إعادة توزيع واضحة لكل ملف؛ لذلك لم أضمّن تسجيلًا من دون إذن مناسب. يلزم اختيار تسجيل مرخّص ثم دمجه واختباره في Android.
- النص القرآني ومواقيت الصلاة ومصادر الصوت تحتاج مراجعة واختبارًا شرعيًا وتقنيًا قبل النشر.

## الخصوصية
لا تُرسل بيانات السبحة أو الإعدادات إلى خادم. يُطلب الموقع فقط عند اختيار المستخدم تحديد الموقع، وتُستخدم الإحداثيات لطلب مواقيت الصلاة من خدمة AlAdhan.
